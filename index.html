Your personal income & expense tracker

One-time setup. This app saves your entries to your own free Supabase project, so nothing is lost even if you clear your browser.

1. Create a free project at supabase.com
2. In the SQL editor, run:

create table entries (
 id text primary key,
 type text, amount numeric,
 category text, date date,
 note text, created_at timestamp default now()
);
alter table entries enable row level security;
create policy "public access" on entries for all using (true);
